Setting it up on Cloudflare

  • Cloudflare dashboard → Email → Email Sending → add liquidatorusa.com. Cloudflare adds the DNS records (SPF, DKIM) for you.
  • SMTP_FROM must be an address on that domain, e.g. sales@liquidatorusa.com. Set it under the Worker's Settings → Variables.
  • The Workers Paid plan includes 3,000 emails a month, then $0.35 per 1,000.
  • Invoices print the PAYMENT_INSTRUCTIONS setting (Zelle, bank transfer, check…).
