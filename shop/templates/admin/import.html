How it works

  • Rows are matched by SKU. New SKUs are created, and existing ones are updated. Blank cells leave the current value unchanged.
  • English, Chinese or bilingual column headers all work. Title rows above the header are skipped.
  • New categories and factories are created automatically by name.
  • Quote only = yes hides the price (price can be blank).
  • If any row has an error, nothing is imported. Fix the file and upload it again.
